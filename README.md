# Manipulator CBF-RL

面向机械臂的安全强化学习研究:在 GPU 并行仿真环境中,使用控制障碍函数(CBF)
对强化学习策略的输出动作进行实时安全滤波,保证机械臂始终处在解析的安全边界内,
并研究安全滤波对训练吞吐与收敛特性的影响。

## 性能对比

### 安全收益:任务指令越界压力测试

安全滤波的价值体现在任务指令超出安全边界时——这恰是数据采集/部署时
最常见的安全风险来源(任务外推、错误指令、远程操控失误)。压力测试设定:
参考目标从安全边界内跳至边界外 4–10 cm 并保持 3.2 秒(64 个并行环境、
480 个控制步、同一组名义命令),分别以原始命令和 CBF 滤波命令执行:

| 指标 | 无保护执行 | CBF 滤波执行 |
|---|---:|---:|
| 越界采样率 | **58.1%** | **0%** |
| 最小边界余量 | **-99.0 mm** | **+10.0 mm** |
| 命令干预率 | — | 55.4%(全部低秩闭式投影,无需 QP 回退) |
| 跟踪 RMSE | 0.103 m | 0.152 m |

无保护命令使机械臂在安全区外停留近 1 秒、最深越界 99 mm;CBF 滤波将全部
越界命令在执行前拦截,最小余量始终 ≥ +10 mm,代价是跟踪误差小幅上升
(安全与任务的权衡)。

### 滤波开销与吞吐(同一压力场景实测,256 个并行环境)

压力场景下每批约 55% 的名义命令需要干预,是滤波开销最重的工况
(常规任务下成本更低)。单项滤波延迟包含每步安全约束的构建:

| 配置 | 单批滤波延迟(均值 / p95) | 端到端吞吐(相对) |
|---|---:|---:|
| 无保护 | — | 16344 samples/s(100%) |
| CBF + 完整 QP 求解(含可行旁路) | 95.4 / 196 ms | 2246 samples/s(13.7%) |
| CBF + 低秩近似(完整求解回退) | **8.25 / 14.0 ms** | **9651 samples/s(59.0%)** |

低秩近似把单批(256 环境)滤波延迟降低 **11.6 倍**,在最重负载工况下仍保持
无保护吞吐的约 **60%**;完整求解方案则只剩 14%。越界命令越多,低秩近似的
优势越大——安全风险最高的场景,恰是该滤波器最快的场景。

## 为什么适合真机数据采集

该框架的动作层安全护栏与数据采集天然匹配:采集过程中策略输出、远程操控、
任务外推都可能产生越界命令,而 CBF 滤波在**动作产生前**将不安全命令拦下
(压力测试中 55% 的命令被拦截、零违例),即使压力工况下端到端吞吐仍保持
无保护的约 60%。真机部署仍需按真实动力学(跟踪滞后、关节-接触约束)
校准安全余量与滤波增益,本工作验证的是动作层护栏与系统可行性。
